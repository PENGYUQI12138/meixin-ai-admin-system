# M4-A：教师实际授课课时

基线：`origin/main` 4125002；已核对生产标签 `prod-m3-2026-09-24` 指向 1fe27cf。开发分支：`m4-teacher-payroll`。本阶段只记录授课事实，不生成工资、应付、付款或会计记录。

## 记录口径

- 一张已完成且未撤销的 `MX Session Execution` 最多有一笔教师授课确认。教师、课程、排课、执行单从已确认的原排课和执行单读取并保存快照。
- 排课的 `start_at/end_at` 是计划时间；教师课时只取人工输入的 **实际授课起止时间**，按整分钟差 `effect_minutes` 记录，汇总课时为 `SUM(effect_minutes)/60`。不足一分钟不能确认为授课。不乘学生人数，不读取 `MX Lesson Consumption Entry` 的数量或效果。
- 学生请假、缺勤及不同课消规则本身不改变教师分钟数。全部学生未到课时，实际授课或未授课都属于异常，须管理员确认。只要有学生标为到课，就不能确认“未授课”；应先纠正执行单。
- 实际时间不能在未来，时长限 1–1440 分钟。实际时间早于计划开始、晚于计划结束、与计划时长相差超过 15 分钟，或无人到课，须 `Meixin Manager` 提供非空原因。15 分钟是 M4-A 暂行异常阈值，薪酬政策确认前不用于计薪舍入。普通记录可由 `Meixin Scheduler` 确认。
- “未授课”不填实际时间，记录 0 分钟并要求管理员说明。已取消而从未完成的排课没有执行单，也不产生教师课时。0 分钟保留决策证据。

## 审计与纠错

新 DocType `MX Teacher Hour Entry` 是不可修改、不可删除的确认/撤销流水，保存确认人、时间、原始执行单、原排课、教师及课程快照、计划与实际时间、异常原因、唯一幂等键。业务角色只读；唯一受控写入口是 `confirm_teaching`。

确认与执行单取消沿用 M1 的同一 MariaDB 事务写锁。重复确认同一执行单且内容相同则返回原记录；内容不同则拒绝；数据库唯一幂等键防止重试写出相同流水。管理员取消执行单时，同事务为已有教师记录追加相反分钟数；修订的新执行单可另行确认。原确认及撤销均保留。取消执行单过程中若课消或教师流水出错，整笔事务回滚。

## 隔离验证

`deploy/test-env.ps1 -Generation M4` 启动 `meixin_m4_test` Docker 项目、`test_meixin_m4.localhost` 站点、独立 MariaDB/站点卷和 18084 端口；只使用 `TEST-M4-*` 虚构数据。M1/M2/M3/M4 集成测试在该站点运行，CI 静态与单元测试随独立分支 push 触发。

## 后续须确定的薪酬政策

计薪单位及舍入、不同课程/教师费率、多人共教或代课分配、无人到课但教师待命是否计薪、超时/提前开始的审批阈值、节假日和跨日计薪、结算周期与复核权限、取消后的已结算调整方式。本阶段不预设这些规则。
