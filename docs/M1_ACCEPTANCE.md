## 浏览器控制台和实时连接

首次检查发现测试入口没有代理 `/socket.io`，浏览器收到 404。已将隔离 Compose 入口改为 Nginx，并让实时请求保留浏览器公开 Host/端口；同时取消容器重建时对 PyPI 构建依赖的下载。

修复后验证：

- 登录入口返回 HTTP 200。
- `GET /socket.io/?EIO=4&transport=polling` 返回有效 Engine.IO 握手包。
- 在全新浏览器页重新加载带教师与教室筛选的周课表，控制台结果为 `[]`，即 0 条 error、0 条 warn。
- 冲突提交旧页曾记录一次 Frappe `ValidationError`，它对应验收时故意触发并由界面正确显示的业务拒绝，不是未处理的成功路径错误。
